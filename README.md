# Hatch Legends

A complete, ready-to-publish **pet simulator** for Roblox, in the same genre as Pet Simulator 99 and Bee Swarm Simulator.
Players collect coins, hatch eggs for pets that multiply their earnings, unlock new worlds, and rebirth for permanent boosts.

Everything is code. The whole map, the UI, and the pets are generated by scripts, so the game runs with **zero external assets**.
You can open it in Roblox Studio and press Play right away.

**Looks:** every pet is a detailed 3D model built from parts (ears, tails, wings, horns, crowns, halos), with sparkles, fire and auras on rare pets.
The world is Smooth Terrain with rivers, lava, mountains, a volcano and planets, and each zone has its own lighting, sky colour and weather.

### How the game makes money

Seven **gamepasses** (one-time purchases) and ten **developer products** (repeatable purchases) are already built in.

| Gamepass | Suggested price | Effect |
|---|---|---|
| 2x Coins | R$249 | Doubles all coin income |
| VIP | R$399 | +25% coins, +1 pet slot, 2x daily rewards, [VIP] chat tag |
| Auto Collect | R$199 | Orb magnet with a 32-stud radius |
| Lucky | R$299 | Doubles the odds weight of Legendary and Mythic pets |
| +3 Pet Slots | R$199 | Equip 3 more pets |
| Triple Hatch | R$249 | Hatch 3 eggs at once |
| Auto Hatch | R$349 | Keeps hatching anywhere in the egg's zone, waiting for coins when short |

Developer products cover four coin packs, three gem packs, a luck potion, a coin potion, and an instant rebirth.
Coin packs and coin rewards pay a set number of minutes of the player's current income. A R$49 pouch is always worth 10 minutes of play, from the first zone to the last.

Upsells appear where players feel the need. Locked "x3" and "AUTO" buttons sit right in the egg menu.
A green **+** next to coins and gems opens the shop.

## Quick start

### Option A: open the ready-made place file (easiest)

You need a Windows PC or a Mac. Roblox Studio doesn't run on phones or tablets.

1. **Install Roblox Studio** for free from [create.roblox.com](https://create.roblox.com/) and sign in.
2. **Download the game file.** On GitHub, open [`build/HatchLegends.rbxl`](build/HatchLegends.rbxl) and click the **Download raw file** button, the arrow icon at the top right of the file view.
3. **Open it.** Double-click the downloaded file, or in Roblox Studio use **File > Open from File** and pick it.
4. **Press Play** (F5). The world, terrain and pets build themselves in a few seconds. The editor view looks empty before that, which is normal.

Tip: for the best look, set Roblox's graphics quality high (in Studio: **File > Studio Settings > Rendering > Quality Level**).

If your browser saves it as `HatchLegends.rbxl.txt` or similar, rename it so it ends in `.rbxl`.
`build/HatchLegends.rbxlx` is the same game in text format, in case the first file won't open.

> These files are snapshots. If you change files in `src/`, rebuild them with Option B.

### Option B: build from source with Rojo (for developers)

1. Install [Rokit](https://github.com/rojo-rbx/rokit), then run `rokit install` in this folder. That installs Rojo.
2. Build the place:
   ```bash
   ./scripts/build.sh            # writes HatchLegends.rbxlx
   ```
3. To live-sync while you edit, install the Rojo Studio plugin, run `rojo serve`, and click **Connect** in Studio.

## Before you publish (checklist)

Follow [docs/MONETIZATION_SETUP.md](docs/MONETIZATION_SETUP.md) for the step-by-step version.

1. **Publish the place.** In Studio, use **File > Publish to Roblox** and create a new experience.
2. **Turn on saving in Studio** (optional, for testing). Go to **Game Settings > Security** and enable **Studio Access to API Services**.
   Without it, Studio uses a temporary in-memory save and prints a warning. Live servers always save.
3. **Create the gamepasses and developer products** on the [Creator Hub](https://create.roblox.com/dashboard/creations).
   Paste each Id into `Config.Gamepasses` and `Config.Products` in `src/Shared/Config.lua`.
4. **Set your group.** Put your group's Id in `Config.GroupId` to turn on the group reward.
5. **Turn off free Studio passes** if you want to test buying. `Config.Debug.FreeGamepassesInStudio` gives you every gamepass in Studio so you can test them. It never affects live servers.
6. **Change the promo codes** in `src/Server/Codes.lua`. The defaults are `RELEASE`, `HATCH` and `LUCKY`. That file is server-only, so players can't read upcoming codes.
7. **Fill out the Maturity & Compliance questionnaire** on the Creator Hub. Roblox requires it before an experience can be public.
8. **Set the server size.** In **Game Settings > Places**, set **Max Players** to about 12. Simulators feel best with a busy but not crowded server.
9. **Add an icon and thumbnails.** They matter more than anything else for getting clicks. See the launch guide.

## Customising

Almost everything lives in **`src/Shared/Config.lua`**.

- **Add a pet:** add a line to `Config.Pets`, then put it in an egg's `Pets` list.
- **Add an egg:** add an entry to `Config.Eggs` with a `Zone`. The stand appears automatically in that zone.
- **Add a zone:** append to `Config.Zones`. The map, bridge, gate and orbs are generated for it.
- **Tune the economy:** change orb values, egg costs, zone costs and rebirth settings. The comment above `Config.Zones` lists the simulated pacing. Run the tests after changes to catch broken data.
- **Change how a pet looks:** edit its line in `src/Shared/PetStyles.lua`. Pick a body type (Dog, Cat, Dragon, Phoenix and more), three colours, an optional material, and extras such as `Crown`, `Halo`, `Fire` or `AngelWings`.
- **Real pet models:** put a Model named exactly like a pet (for example `Dog`) inside `ReplicatedStorage > PetModels`. It replaces the generated model automatically.
- **Quests, events and upgrades:** tune `Config.Quests`, `Config.Events` and `Config.Upgrades`. Golden and Rainbow recipes are in `Config.PetTiers`.
- **Sounds:** paste sound asset Ids you own or that are free to use into `Config.Sounds`.
- **Wipe all player data:** change `Config.DataStoreName`. Do this only before launch.

Odds in each egg are percentages and must add up to 100.

### Checking your changes

Run the offline tests after editing `Config.lua` or `PetStyles.lua`. They check egg odds, pet references and looks, quests, upgrades, purchase rules and save-data format. You need the [Luau CLI](https://github.com/luau-lang/luau/releases) on your PATH.

```bash
./scripts/test.sh
```

### Fair-play rules built in

All eggs count as "paid random items" under Roblox rules, because coins and gems can be bought with Robux.
The game already handles this:

- The egg menu lists every pet and its exact odds before you hatch. Displayed odds always add up to exactly 100%.
- When a luck boost is active, the displayed odds update to the boosted numbers.
- Players in regions where paid random items are restricted cannot buy coins, gems or luck boosts. Their eggs are paid for only with currency earned by playing.

Read the official [paid random items policy](https://create.roblox.com/docs/production/monetization/paid-random-items) before you add new paid items.

## Project layout

```
src/
  Shared/               ReplicatedStorage.Shared (used by server and client)
    Config.lua          all game data and tuning
    PetStyles.lua       how each pet looks (body type, colours, extras)
    Remotes.lua         list of RemoteEvents / RemoteFunctions
    Util.lua, Signal.lua
  Server/               ServerScriptService
    Server.server.lua   starts every service in order
    Codes.lua           promo codes (server only)
    Services/           Data, Gamepass, Economy, Map (+ MapDecor), Pet, Zone,
                        Rebirth, Reward, Quest, Event, Upgrade, Shop,
                        Collectible, Leaderboard, Player, Compliance
  Client/               StarterPlayerScripts
    Client.client.lua   starts every controller in order
    Modules/            ClientState (local copy of player data), UIKit,
                        PetBuilder (3D pet models and previews)
    Controllers/        HUD, windows, hatch animation, orbs, pets, ambience
                        and weather, egg boards, quests, events, upgrades
docs/
  MONETIZATION_SETUP.md  creating passes and products, step by step
  LAUNCH_GUIDE.md        how to get players and grow revenue
build/
  HatchLegends.rbxl      ready-to-open place file (Roblox Studio format)
  HatchLegends.rbxlx     the same place in text format
```

The server owns all game state. The client only shows it and sends requests, which the server checks.

Read **[docs/LAUNCH_GUIDE.md](docs/LAUNCH_GUIDE.md)**. It covers thumbnails, codes, ads, update cadence, the metrics Roblox's algorithm watches, and how payouts work.

Be realistic about one thing. No code can guarantee a hit.

This project gives you a solid, monetized foundation. Custom pet art, a great thumbnail, steady updates and promotion are what turn it into a popular game.
