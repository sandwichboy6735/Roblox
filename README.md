# Brainrot Obby

A complete, ready-to-publish **obby** (obstacle course) for Roblox where you play as absurd **brainrot** characters: a shark in sneakers, a banana on bongos, a coffee cup ballerina, a nonna with a bomb.
Run 100 stages across 6 worlds, collect coins, unlock brainrots that run faster, jump higher and have special moves, then prestige and do it all again for bigger rewards.

Everything is code. The whole course, the characters and the menus are generated by scripts, so the game runs with **zero uploaded assets**.
Open it in Roblox Studio and press Play.

## What's in the game

| System | What it does |
|---|---|
| **100 stages, 6 worlds** | Meme Meadow, Pasta Beach, Sahur Jungle, Cappuccino City, Crocodilo Skies and Brainrot Void. Each world has its own look, sky, weather and scenery. |
| **11 obstacle types** | Jumps, lava stepping stones, moving platforms, spinning kill bars, vanishing platforms, conveyor belts, climbing walls, narrow beams, jump pads, pillars and sliding walls. They get harder stage by stage. |
| **24 brainrots** | Common to Mythic, each a 3D character you wear. Every one has its own speed and jump power. |
| **Perks** | Double Jump, Dash (Q key or a touch button), Glide (hold jump), Coin Magnet and Coin Boost. Better brainrots make the hard stages possible. |
| **Coins** | Floating coins on every stage and a reward for each new stage. Coins come back after 90 seconds. |
| **Checkpoints** | Glowing pads save your spot. Fall or touch lava and you're back on the pad in a second. A RESET button and a STAGES menu let you jump back to any pad you've reached. |
| **Prestige** | Beat stage 100 and walk into the portal: back to stage 1 with +50% coins forever, a coin bonus and prestige-only brainrots. |
| **Run timer** | Every run is timed. The fastest full runs go on a leaderboard. |
| **Free unlocks** | Reach stage 30 and 60, or prestige, and you get free brainrots. |
| **Daily streak** | 7 days of login rewards ending in a free brainrot. |
| **Playtime gifts** | 6 coin gifts unlock during a session. |
| **Promo codes** | Hand out codes on social media and YouTube. |
| **Group bonus** | +10% coins and free coins for joining your Roblox group. |
| **Leaderboards** | Top stage, top prestige and fastest run on 3D boards in the lobby. |
| **Lobby** | Spawn plaza with statues of the best brainrots, a how-to sign and arrows to stage 1. |
| **Safe saving** | DataStore saving with session locking, retries, autosave and shutdown saves. |
| **Anti-exploit** | Checkpoints must be touched in order, near the pad, no faster than the brainrot can run. Coins are checked for distance. Skips come only from real purchases. |

## Quick start

### Option A: open the ready-made place file (easiest)

You need a Windows PC or a Mac. Roblox Studio doesn't run on phones or tablets.

1. **Install Roblox Studio** for free from [create.roblox.com](https://create.roblox.com/) and sign in.
2. **Download the game file.** On GitHub, open [`build/BrainrotObby.rbxl`](build/BrainrotObby.rbxl) and click the **Download raw file** button, the arrow icon at the top right of the file view.
3. **Open it.** Double-click the downloaded file, or in Roblox Studio use **File > Open from File** and pick it.
4. **Press Play** (F5). The whole course builds itself in a few seconds. The editor view looks empty before that, which is normal.

If your browser saves it as `BrainrotObby.rbxl.txt` or similar, rename it so it ends in `.rbxl`.
`build/BrainrotObby.rbxlx` is the same game in text format, in case the first file won't open.

> These files are snapshots. If you change files in `src/`, rebuild them with Option B.

### Option B: build from source with Rojo (for developers)

1. Install [Rokit](https://github.com/rojo-rbx/rokit), then run `rokit install` in this folder. That installs Rojo.
2. Build the place: `./scripts/build.sh` creates `BrainrotObby.rbxlx`. Open it in Studio.
3. To live-sync while you edit, install the Rojo Studio plugin, run `rojo serve`, and click **Connect** in Studio.

## Before you publish (checklist)

1. **Publish the place.** In Studio, use **File > Publish to Roblox** and create a new experience.
2. **Turn on saving in Studio** (optional, for testing). Go to **Game Settings > Security** and enable **Studio Access to API Services**.
   Without it, Studio uses a temporary in-memory save and prints a warning. Live servers always save.
3. **Create the gamepasses and products** on the Creator Hub and paste their Ids into `src/Shared/Config.lua`. Step-by-step: [docs/MONETIZATION_SETUP.md](docs/MONETIZATION_SETUP.md).
4. **Set your group.** Put your group's Id in `Config.GroupId` to turn on the group reward.
5. **Change the promo codes** in `src/Server/Codes.lua`. The defaults are `RELEASE`, `BRAINROT` and `SAHUR`.
6. **Play it through.** Walk the first 20 stages in Studio. If a jump feels unfair, lower that world's `Difficulty` in `Config.Worlds`.
7. **Add an icon and thumbnails.** They matter more than anything else for getting clicks. See [docs/LAUNCH_GUIDE.md](docs/LAUNCH_GUIDE.md).

## Customising

Almost everything lives in **`src/Shared/Config.lua`**.

- **Add a brainrot:** add a line to `Config.Brainrots` (stats, price, perk) and its look to `src/Shared/BrainrotStyles.lua` (body plan, three colours, extras such as `Sneakers`, `Crown`, `Jet`, `Bombs`).
- **Real character models:** put a Model named exactly like a brainrot inside `ReplicatedStorage > BrainrotModels`. It replaces the generated one automatically.
- **Change the course:** edit `Config.Worlds` (stage counts, difficulty ranges, colours) or change `Config.Course.Seed` for a completely different layout. Obstacle types live in `src/Server/Services/CourseBuilder.lua`.
- **Tune the economy:** coin values and stage rewards per world, brainrot prices, `Config.Prestige`.
- **Rewards and codes:** `Config.DailyRewards`, `Config.PlaytimeRewards`, `src/Server/Codes.lua`.
- **Sounds:** paste sound asset Ids you own or that are free to use into `Config.Sounds`.
- **Wipe all player data:** change `Config.DataStoreName`. Do this only before launch.

### Checking your changes

Run the offline tests after editing `Config.lua`, `BrainrotStyles.lua` or `Codes.lua`. They check the worlds, difficulty curve, brainrot stats and looks, prices, rewards and the save-data format. You need the [Luau CLI](https://github.com/luau-lang/luau/releases) on your PATH.

```bash
./scripts/test.sh
```

## Project layout

```
src/
  Shared/               ReplicatedStorage.Shared (used by server and client)
    Config.lua          all game data and tuning
    BrainrotStyles.lua  how each brainrot looks
    BrainrotBuilder.lua builds the 3D characters from parts
    Remotes.lua, Util.lua, Signal.lua
  Server/               ServerScriptService
    Server.server.lua   builds the course, starts every service
    Codes.lua           promo codes (server only)
    Services/           CourseBuilder (+ CourseDecor), Mover, Stage, Coin,
                        Brainrot, Economy, Data, Gamepass, Shop, Reward,
                        Leaderboard, Player, RateLimiter
  Client/               StarterPlayerScripts
    Client.client.lua   starts every controller in order
    Modules/            ClientState, UIKit, FloatingText, RewardText
    Controllers/        HUD, brainrot menu, shop, stages, rewards, settings,
                        movement perks, coins, effects, ambience, trails, chat
docs/
  MONETIZATION_SETUP.md  creating passes and products, step by step
  LAUNCH_GUIDE.md        how to get players and grow revenue
build/
  BrainrotObby.rbxl      ready-to-open place file (Roblox Studio format)
  BrainrotObby.rbxlx     the same place in text format
archive/
  HatchLegends.rbxl      the earlier pet simulator built in this repo
```

The server owns all progress. The client only shows it, moves the character, and sends requests the server checks.
